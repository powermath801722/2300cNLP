02 · Concepts

How it works

Natural language inference

NLI asks: given a premise, is a hypothesis definitely true (entailment), definitely false (contradiction), or undetermined (neutral)? SNLI (570k pairs from image captions) and MultiNLI (433k pairs across ten genres) made it a large-scale supervised task. A cross-encoder reads both sentences together and outputs three logits.

The entailment trick

Yin, Hay and Roth (2019) recast classification as NLI: premise = your text, hypothesis = a template filled with a label. The label whose hypothesis is most entailed wins. Because labels are read as natural language, the model can use what it knows about the words “sports” or “complaint” without any task-specific training.

Single- vs multi-label scoring

Single-label: softmax the entailment logits across all labels, so scores sum to 1 and labels compete. Multi-label: for each label separately, softmax over its own entailment and contradiction logits (neutral dropped), so several labels can all score high, or all low.

Templates matter

The hypothesis wording is part of the model input. “This example is positive.” and “The sentiment of this review is positive.” can give different scores for the same text. Prompt sensitivity like this is a known weakness; choosing templates on a small labelled dev set is common practice.

Cost and limits

Each label costs a full forward pass, so 20 labels means 20 passes; bi-encoders that embed text and labels separately are faster but usually less accurate. Zero-shot works best for topical labels the NLI data covers; fine-grained or domain-specific labels usually still need labelled data.

This model

cross-encoder/nli-deberta-v3-xsmall: DeBERTa-v3 extra-small (about 22M backbone parameters plus a 128k-token embedding matrix) trained on SNLI and MultiNLI, converted to ONNX and quantized to 8 bits by Xenova. DeBERTa adds disentangled attention over content and relative position; v3 pre-trains with ELECTRA-style replaced-token detection.
