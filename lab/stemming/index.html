Porter writes every word as [C](VC)m[V]: C = run of consonants, V = run of vowels (y counts as a vowel after a consonant). Most rules only fire when m is large enough, which stops short words like “sing” from losing “-ing”.

04 · Concepts

How it works

Stemming

Strips affixes with string rules to reach a stem, which need not be a word (“poni”, “gener”). Porter’s 1980 algorithm runs five ordered steps of about 60 rules. It’s fast, needs no dictionary, and is still a standard baseline in information retrieval.

Lemmatization

Maps a word to its dictionary form, the lemma (“went” → “go”, “mice” → “mouse”). It needs a lexicon, exception lists for irregular forms, and the part of speech: “meeting” is meet as a verb but meeting as a noun.

How this lemmatizer works

Like WordNet’s morphy: check an irregular-forms table, then apply suffix-detachment rules for the part of speech (−ies → −y, −ing → −e or ∅, undoubling “runn” → “run”) and keep candidates that exist in a lexicon. Here the lexicon is the 30,000-word Word2Vec vocabulary; ties go to the more frequent word.

Morphology

Inflection changes grammatical features without changing the word’s category (walk, walks, walked). Derivation builds new words, often of a new category (nation → national → nationalize). Porter removes both; lemmatizers usually only undo inflection.

Precision vs recall

In search, stemming raises recall (a query for “connect” also finds “connections”) but can lower precision (“university” matches “universe”). Light stemmers that only strip plurals, or lemmatization, trade some recall back for precision.

Beyond English

Rule-based stemming is far harder in morphologically rich languages like Finnish or Turkish, where one word can carry several suffixes. Snowball provides stemmers for many languages; modern neural models sidestep the issue with subword tokenization.
