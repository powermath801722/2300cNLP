02 · Concepts

How it works

Input packing

Question and passage go in as one sequence: [CLS] question [SEP] passage [SEP]. Self-attention lets every passage token look at the question, so the representation of “1843” knows it is being asked about a date.

Start and end logits

Two linear heads on top of each token’s final hidden state produce a start score and an end score. Training maximizes the log-probability of the gold start and the gold end token, each softmaxed over the sequence.

Span scoring

At inference every span (s, e) with s ≤ e and a maximum length (30 tokens here) is scored as start_logit[s] + end_logit[e], equivalently P(start)·P(end). Spans must lie inside the passage and may not start or end in the middle of a word.

SQuAD 1.1 vs 2.0

SQuAD 1.1 (100k+ questions on Wikipedia) always has an answer in the passage, so a model trained on it always returns something. SQuAD 2.0 adds 50k unanswerable questions; models learn to put weight on the [CLS] token as a “null” span and abstain when its score beats the best span by a tuned threshold. This model is a 1.1 model, so the page uses a simpler stand-in: abstain when the best span’s probability falls below the threshold you set.

Exact match and F1

SQuAD scores answers after normalization (lowercase, strip punctuation and the articles a/an/the, collapse whitespace). Exact Match is 1 if the strings are identical; F1 is computed on word overlap between prediction and gold, taking the best over all gold answers. The preset questions here have gold answers so you can see both.

This model

distilbert-base-cased-distilled-squad: DistilBERT (6 layers, 66M parameters, distilled from BERT-base) fine-tuned on SQuAD 1.1 with knowledge distillation, reported around 87 F1 on the SQuAD 1.1 dev set. Input is truncated at 384 tokens.
