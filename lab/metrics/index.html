BLEU (with the default exp smoothing) and chrF were checked against sacreBLEU 2.6.0’s sentence_bleu and sentence_chrf on these cases and agree to two decimals.

How much do the metrics agree with each other?

Kendall’s τ between metrics, over every candidate in every example case (each scored against its own case’s references). This measures agreement between metrics on these constructed examples only; it says nothing about agreement with human judgments.

02 · Concepts

How it works

BLEU

Modified n-gram precision for n = 1…4: each candidate n-gram counts at most as often as it appears in any single reference. The geometric mean is exp(Σ ¼ log pₙ), times a brevity penalty BP = min(1, e^(1 − r/c)) for a candidate of length c and closest reference length r. BLEU was designed for whole test sets. On single sentences, any missing 4-gram makes it 0 without smoothing.

ROUGE

Recall-oriented overlap for summarization. ROUGE-N counts shared n-grams; ROUGE-L uses the longest common subsequence, rewarding in-order matches without requiring them to be adjacent. Here P, R and F1 use lowercased word tokens without stemming, so scores differ slightly from the reference implementation with stemming on.

chrF

Character n-gram F-score (Popović 2015): precision and recall for character n-grams of lengths 1–6 (spaces removed) are averaged across lengths, then combined as F_β with β = 2, weighting recall twice as much as precision. Partial credit for morphology (“postponed” vs “postpone”) makes it more robust than BLEU on single sentences and for morphologically rich languages.

BERTScore (as computed here)

Each token is embedded in context. Precision averages each candidate token’s best cosine match in the reference; recall does the reverse, and F is their harmonic mean (Zhang et al. 2020). This page uses all-MiniLM-L6-v2’s last layer with no IDF weighting and no baseline rescaling. The paper’s recommended setup is roberta-large (layer 17) with rescaling, so these numbers aren’t comparable to published BERTScores. MiniLM’s cosines sit in a narrow high band, so focus on differences between candidates.

Why the cases fool overlap metrics

Overlap metrics reward surface form, not meaning. A paraphrase shares few n-grams with its reference, while one changed word (“week” → “year”) or an inserted “not” keeps almost every n-gram. More references help, because each covers different valid phrasings. Embedding metrics give paraphrases more partial credit than BLEU does, but in these examples they still rank negated and role-swapped candidates above faithful paraphrases.

What the field does

Shared tasks compare metrics with human judgments, and learned metrics (COMET, BLEURT) correlate far better than BLEU with modern MT systems. BLEU is still reported because it is cheap and reproducible. Use sacreBLEU’s signature so numbers are comparable, and report several metrics plus human evaluation for strong systems.
