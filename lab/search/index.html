      02 · Concepts

      How it works

      Inverted index

      Instead of scanning every document for every query, the engine stores, for each term, a postings list of the documents that contain it and how often. A query only touches the postings of its own terms. Here the index over ~1,500 paragraphs is built in your browser in a few milliseconds.

      TF-IDF

      A term’s weight in a document grows with its frequency and shrinks with how many documents contain it:

      w(t, d) = (1 + log tft,d) · log(N / dft)

      Documents and the query become weight vectors, and results are ranked by the cosine of the angle between them, which normalizes away document length.

      Okapi BM25

      score(d, q) = Σt∈q IDF(t) · tf·(k₁+1) / (tf + k₁·(1 − b + b·|d|/avgdl)), with IDF(t) = ln(1 + (N − df + 0.5)/(df + 0.5)).

      k₁ controls term-frequency saturation: the tenth occurrence of a word adds much less than the first. b controls length normalization: at b = 0 long paragraphs are not penalized; at b = 1 scores are fully divided by relative length. Move the sliders and watch the BM25 column reorder.

      Stopwords and normalization

      Very frequent function words (the, of, and) carry almost no IDF weight anyway, but removing them shrinks the index and speeds up queries. Real engines also stem or lemmatize (liberties → liberti) so different forms match; this demo matches exact lowercase words so you can see why that matters.

      Keyword extraction

      The terms with the highest TF-IDF weight in a paragraph are frequent there but rare elsewhere, which makes them a cheap, surprisingly good set of keywords. The same idea underlies the classic “characteristic words” of an author or era.

      Evaluating a ranking

      Search quality is measured against human relevance judgments: precision@k (how many of the top k are relevant), recall, mean average precision and nDCG, which rewards relevant results near the top. The overlap figure above only says how much the two rankers agree, not which is right.
