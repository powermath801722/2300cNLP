04 · Concepts

How it works

The Markov assumption

The chain rule gives P(w₁…wₙ) = ∏ P(wᵢ | w₁…wᵢ₋₁). An n-gram model approximates each factor with only the last n − 1 words: P(wᵢ | wᵢ₋₂, wᵢ₋₁) for a trigram. Sentences are padded with <s> and end with </s>.

Maximum likelihood

PMLE(w | h) = c(h, w) / c(h). It fits the training data best, but gives probability zero to anything unseen, so a single new trigram makes the whole test set impossible (infinite perplexity).

Add-k smoothing

(c(h, w) + k) / (c(h) + k·V). Laplace (k = 1) moves far too much mass to unseen events when V is large; small k works better but is still a blunt tool.

Interpolation & backoff

Mix orders: λ₃P(w | uv) + λ₂P(w | v) + λ₁P(w), with Σλ = 1 (here 0.6 / 0.3 / 0.1; normally tuned on held-out data). Stupid backoff (Brants et al., 2007) uses the highest order with a count and multiplies by 0.4 each step down; its scores don’t sum to 1, so it can’t be evaluated by perplexity.

Kneser–Ney

Subtract a discount D from every seen count and give that mass to a lower-order model. The lower order uses continuation counts: how many different words precede w, not how often w occurs. “Francisco” is frequent but only follows “San”, so it should be an unlikely guess after a new context.

Perplexity

PP = 2−(1/N) Σ log₂ P(wᵢ | h): the geometric mean inverse probability per token, or the effective number of equally likely choices. Compare perplexities only with the same vocabulary and test set. Words seen once in training are mapped to <UNK> here so every test word has a probability.
