01 · Try it

Hide a signal in sampled text

Before each token is sampled, the previous token and a secret key pick a pseudo-random “green list” covering a fraction γ of the vocabulary, and green tokens get +δ added to their logits. Readers can’t see it; a detector that knows the key counts green tokens and runs a z-test. Both texts below come from the same prompt and the same random seed, one with the watermark and one without. For both runs, end-of-text and back-to-back line breaks are blocked so each text reaches the chosen length (small GPT-2 models otherwise fall into newline loops).

02 · Attack it

How much editing does it survive?

Replace or delete a fraction ε of the watermarked tokens at random. Each edit can break the green status of the edited token and of the one after it (whose green list depends on its predecessor), so z falls roughly linearly with ε. 04 · Concepts

How it works

The soft red-list watermark

At step t, hash the previous token st−1 with a secret key to seed a random partition of the vocabulary into a green list G (size γ|V|) and a red list. Add δ to every green logit, then sample as usual:

p̂ₖ = exp(lₖ + δ·[k ∈ G]) / Σᵢ exp(lᵢ + δ·[i ∈ G])

Here each token’s green status is a keyed hash of (previous token, token), which gives each token an independent γ chance of being green, equivalent in distribution to the paper’s seeded permutation.

Detection is a z-test

Under the null hypothesis (text written without knowledge of the key), each scored token is green with probability γ independently, so the green count |s|G over T tokens is Binomial(T, γ):

z = (|s|_G − γT) / √(T γ (1 − γ))

Kirchenbauer et al. use z > 4 (one-sided p ≈ 3×10⁻⁵) as the threshold. z grows like √T, so longer texts are detected more reliably.

Entropy decides everything

The bias only helps when the model is choosing among several plausible tokens. In low-entropy stretches (“…the United States of America”) one token dominates whatever δ is, so it carries little watermark. The paper bounds the expected green fraction using the “spike entropy” of each step’s distribution; the run log shows mean per-token entropy for comparison.

Quality cost

Larger δ makes detection easier but moves the distribution away from the model’s, raising perplexity under the unwatermarked model. Smaller γ makes each green hit more informative but forces more distortion. Kirchenbauer et al. found γ = 0.25, δ = 2 a reasonable middle point; the perplexity column lets you measure the trade-off here.

Distortion-free schemes

Aaronson’s Gumbel-max scheme picks argmaxₖ rₖ1/pₖ with keyed pseudo-random rₖ, which samples exactly from p for a random key; Kuditipudi et al. (2023) make such schemes robust to edits by aligning the text with a long key sequence. These keep each single sample unbiased, at the cost of deterministic outputs for a fixed key and context.

Limits

Detection needs the tokenizer and key, so the key holder controls who can check. Paraphrasing with another model, translation round-trips, or mixing watermarked and human text all dilute the signal, and repeated n-grams inflate z unless each (previous, token) pair is scored once. Watermarks are evidence about one generator’s use, not a general AI-text detector.
