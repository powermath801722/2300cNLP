02 · Concepts

How it works

One distribution per step

An autoregressive model factorizes a sequence as a product of next-token conditionals. At each step it outputs logits z over the 50,257-token GPT-2 vocabulary; softmax turns them into probabilities. Generation is a loop: choose a token, append it, run the model again.

P(x₁…x_T) = ∏ₜ P(xₜ | x₍<t₎) pᵢ = exp(zᵢ / T) / Σⱼ exp(zⱼ / T)

Greedy and beam search

Greedy takes the argmax at every step. Beam search keeps the W partial sequences with the highest total log-probability, expanding each and pruning back to W; here hypotheses are ranked by log-probability per token (length normalization) so short ones don’t win by default. Both approximate the mode, argmax over all sequences, which is intractable to find exactly.

score(y) = (1/|y|) Σₜ log P(yₜ | y₍<t₎, x)

Temperature

Dividing logits by T before the softmax reshapes the distribution without changing the ranking: T < 1 sharpens it toward greedy (T → 0 is argmax), T > 1 flattens it toward uniform, so rare tokens get sampled more often.

Top-k and nucleus (top-p)

Top-k (Fan et al., 2018) samples only from the k most likely tokens, renormalized. A fixed k is too many when the model is confident and too few when it isn’t. Nucleus sampling (Holtzman et al., 2020) instead keeps the smallest set whose probability mass reaches p, so the candidate pool grows and shrinks with the model’s uncertainty.

V⁽ᵖ⁾ = smallest V′ ⊆ V with Σ_{x∈V′} P(x | x₍<t₎) ≥ p

Degeneration and the probability–quality paradox

Maximization-based decoding produces generic, repetitive text: once a phrase repeats, the model assigns the repeat even higher probability, so loops reinforce themselves. Human text is not the most probable text; its per-token surprisal sits in a “typical” band rather than near zero. Higher likelihood therefore does not mean higher quality past a point; in machine translation the single most probable output is sometimes the empty string (Stahlberg & Byrne, 2019).

Why truncation helps

A trained model spreads a little probability over thousands of implausible tokens. Each is unlikely, but together the tail can hold real mass, and one draw from it can derail everything that follows. Truncation (top-k, top-p) cuts that unreliable tail before sampling (Hewitt et al., 2022), keeping diversity from the head of the distribution without the occasional nonsense.

Repetition penalty

The CTRL-style penalty (Keskar et al., 2019) discounts every token already in the context: positive logits are divided by θ and negative ones multiplied by θ. It reduces loops but also penalizes legitimate repeats like “the”, so values just above 1 work best.

zᵢ ← zᵢ / θ if zᵢ > 0 and i ∈ context zᵢ ← zᵢ · θ if zᵢ ≤ 0 and i ∈ context

This implementation

All decoding is written by hand on top of raw logits from distilgpt2 (a 6-layer distilled GPT-2 trained by Hugging Face) running in WebAssembly. Each step feeds only the newest token and reuses the cached attention keys and values; beam search batches its hypotheses and reorders the cache to match. Sampling uses a seeded PRNG, so the same seed reproduces the same text. The model is 8-bit quantized, so probabilities can differ slightly from the full-precision model.
