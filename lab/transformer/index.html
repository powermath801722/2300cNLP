05 · Concepts

How it works

The block

Tokens become vectors xt = E[wt] + P[t] (learned token and position embeddings). Each layer adds to this residual stream: x ← x + Attn(LN(x)), then optionally x ← x + MLP(LN(x)). A final LayerNorm and unembedding U give logits, and training minimizes next-token cross-entropy with Adam (Kingma & Ba 2015).

Causal self-attention

Per head, with dh = d / heads: q = xWQ, k = xWK, v = xWV; A = softmax(qkᵀ / √dh + M), where the mask M is −∞ above the diagonal so position t can only see 0…t; the head writes A v WO back into the residual stream (Vaswani et al. 2017).

Hand-written backprop

Every operation records a closure on a tape; running the tape backwards applies the chain rule. The softmax backward is ∂s = A ⊙ (∂A − Σ A ∂A). The gradients were checked against central finite differences in float64 for every parameter tensor (relative error below 10⁻⁷; training/transformer_check.mjs).

The task

Each sequence gets its own random successor map π over 24 tokens: the next token is π(current) with probability 0.75, otherwise random. π changes every sequence, so there is nothing to memorize; the only way to do better than chance is to look back for an earlier occurrence of the current token and copy what came next (in-context bigrams, as in Bietti et al. 2023).

The induction circuit

Two heads in two layers. A previous-token head in layer 1 copies information about token t−1 into position t. An induction head in layer 2 then queries with the current token and matches keys that carry “my previous token was this” — that is, it attends to the position after an earlier occurrence — and copies that token to the output. The key depends on the earlier head’s output: K-composition (Elhage et al. 2021).

Phase change

Loss on recallable tokens sits on a plateau, then drops abruptly as both heads appear together; neither helps alone. Olsson et al. (2022) found the same abrupt formation in models up to tens of billions of parameters, coinciding with a jump in in-context learning. Before it, the model only learns which tokens have appeared in the context (an in-context unigram).

Reading the scores

Previous-token score: average attention from t to t−1 (uniform attention gives about 0.1 here). Induction score: attention mass on positions just after earlier occurrences of the current token, rescaled so 0 = what uniform attention would give and 1 = all attention there. Patterns are evidence, not proof: the ablation table tests whether a head actually matters.

Why the task matters

An earlier version of this page repeated a block of tokens at a fixed distance, and the model “solved” it with a single layer by attending to a fixed offset using position embeddings — no induction needed. Randomizing what repeats and where removed that shortcut. Designing tasks so the intended mechanism is the only good solution is a large part of interpretability research.
