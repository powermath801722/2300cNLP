01 · Try it

Which words made the model decide?

Pick a classifier and a sentence. Three model-agnostic methods explain the same prediction by deleting words and watching the model’s log-odds of positive move. For the two linear models the exact answer is known, so you can grade each method.

Faithfulness: delete the “most important” words first

If an explanation is faithful, removing its top-ranked words should drop the predicted-class probability fastest (deletion, lower is better), and adding them back to an empty sentence should restore it fastest (insertion, higher is better). Random orderings are the baseline. AOPC is the average drop over all deletion steps (Samek et al. 2017).

03 · Concepts

How it works

The setup

We explain f(x) = log P(pos|x) − log P(neg|x). A sentence has M words; a coalition z ∈ {0,1}M keeps the words with zj = 1 and deletes the rest. Every method here only queries f on such perturbed sentences, so it works on any model, at the price of feeding it ungrammatical inputs it never saw in training.

Occlusion (leave-one-out)

aj = f(x) − f(x∖j): M + 1 queries and fully deterministic. It measures each word’s effect given all the others, so redundant evidence (“good, really good”) gets little credit, because deleting one copy changes nothing.

LIME

Ribeiro et al. (2016) sample random deletions, weight each sample by an exponential kernel on its cosine distance to the original, π(z) = exp(−d(z)²/σ²) with σ = 25 (distance ×100), and fit a weighted ridge regression f(z) ≈ β₀ + Σ βj zj. The coefficients are the explanation. Results depend on the kernel width, the regularization and the sample.

KernelSHAP

Lundberg & Lee (2017) show that weighted regression with the Shapley kernel π(z) = (M−1) / (C(M,|z|) |z| (M−|z|)) plus the constraint Σφj = f(x) − f(∅) recovers the Shapley values, the unique attribution satisfying efficiency, symmetry, dummy and additivity. Here the constraint is solved exactly; with ≤ 2M − 2 samples every coalition is enumerated and the values are exact, otherwise coalitions are sampled from the kernel in antithetic pairs.

Ground truth for linear models

Naive Bayes is additive in token counts: deleting a token removes exactly log P(w|pos) − log P(w|neg), so all three methods should recover it. The logistic regression uses binary presence features, so a repeated word interacts with its copies: its Shapley value is wv split equally across the copies, while occlusion gives each copy zero. Use the “redundancy” example to see this.

Faithfulness and sanity

Plausible-looking heatmaps prove nothing (Jacovi & Goldberg 2020). Deletion/insertion curves test whether the ranking tracks the model’s behaviour; Adebayo et al. (2018) add sanity checks: an explanation should change when the model’s weights are randomized. Here the logistic-regression weights are permuted; a faithful method’s ranking should become unrelated (ρ ≈ 0). For DistilBERT we test estimator stability across random seeds instead.
