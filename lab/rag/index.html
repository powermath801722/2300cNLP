01 · Try it

Ask a town that doesn’t exist

The knowledge base is 100 short passages about Vellmouth, a fictional delta town written for this demo, plus 10 passages about Vellbridge, a fictional look-alike upstream. No model has seen these facts, so anything correct in an answer has to come from retrieval. Retrieve, generate, then check every sentence of the answer against the passages it was given.

        03 · Concepts

        How it works

        Parametric vs non-parametric memory

        A language model stores facts implicitly in its weights (parametric memory), which is hard to update, hard to inspect and prone to confident invention. Retrieval-augmented generation adds a non-parametric memory: a document index queried at run time, so knowledge can be added or corrected by editing documents, and answers can point to sources.

        The RAG objective

        Lewis et al. (2020) treat the retrieved document z as a latent variable and marginalize over the top-k:

        p(y | x) ≈ Σ_{z ∈ top-k(x)} p_η(z | x) · p_θ(y | x, z)

        with a dense retriever p_η(z | x) ∝ exp(d(z)ᵀq(x)) (DPR) and a seq2seq generator p_θ. This page uses the simpler, now standard retrieve-then-read variant: concatenate the top-k passages into the prompt and decode once (as in Fusion-in-Decoder, which encodes passages separately and lets the decoder attend over all of them).

        Dense, sparse, hybrid

        Dense retrieval embeds queries and passages into one vector space (here all-MiniLM-L6-v2, cosine similarity), so paraphrases match. BM25 matches exact terms, which helps with names and numbers. Reciprocal rank fusion, score(d) = Σ 1/(60 + rank), combines them without calibrating scores.

        Grounding check with NLI

        Fluent is not the same as faithful. Each answer sentence is used as an NLI hypothesis against every retrieved passage (premise); the claim counts as supported if some passage entails it with p ≥ 0.5, contradicted if the best passage contradicts it, otherwise unsupported. The citation shown is the most entailing passage. Faithfulness = supported claims / claims, the idea behind metrics such as RAGAS faithfulness and FActScore. Very short answers (“1342”) are turned into a sentence with the question first.

        Failure modes to try

        Retrieval miss: k = 1 with BM25 on a paraphrased question. Distractors: inject Vellbridge passages and ask about mayors or founding years; a small reader can copy the wrong town’s fact, and the NLI check usually flags it. Closed-book hallucination: without retrieval the model invents a mayor. Abstention: ask something the corpus doesn’t say.

        The models

        Retriever: all-MiniLM-L6-v2, 384-d sentence embeddings; the 110 passage vectors are precomputed with the same model and pooling (8-bit). Generators: LaMini-Flan-T5-77M (Flan-T5-small further tuned on 2.6M instruction responses distilled from larger models) and Flan-T5-small, both 77M parameters. Extractive reader: DistilBERT fine-tuned on SQuAD v1.1. Verifier: DeBERTa-v3-xsmall cross-encoder trained on SNLI + MultiNLI.
